# Echo Tide / 叠影潮

One-screen browser prototype: jump across platforms; every landing stamps a delayed **echo** platform that rises after a lag, then sinks. Reach the exit using self-created temporal platforms — without trapping yourself.

单屏浏览器原型：在平台间跳跃；每次落地会“盖章”一块延迟升起的**回声平台**，随后下沉。用自己创造的时间平台抵达出口，同时避免把自己困住。

## Stack

- Vite + vanilla JS
- `npm test` — smoke asserts
- `npm run build` — production bundle to `dist/`

## Scripts

```bash
npm install
npm test
npm run build
npm run dev
```
